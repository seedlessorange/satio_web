# Open Graph Image Specifications

## Required File
Create `og-image.png` in this folder (`/waitlist/assets/`)

## Dimensions
- **Size:** 1200 x 630 pixels (standard OG image size)
- **Format:** PNG (recommended) or JPG

## Design Guidelines

### Layout
```
┌────────────────────────────────────────────────────────────┐
│                                                            │
│     [Satio Logo]                                           │
│                                                            │
│     The Only Nutrition App                                 │
│     That Truly Understands You                             │
│                                                            │
│     Food · Mood · Sleep · Health · Habits                  │
│                                                            │
│     [Subtle sunflower visualization in background]         │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

### Colors (from brand guide)
| Element | Color | Hex |
|---------|-------|-----|
| Background | Off-white | `#FAFAF8` |
| Primary text | Dark gray | `#2D2D2D` |
| Accent/Logo | Soft Coral | `#E8836B` |
| Secondary accent | Warm Indigo | `#5B5FC7` |

### Typography
- **Font:** Inter
- **Headline:** 48-64px SemiBold
- **Subtext:** 24-32px Regular

### Design Notes
1. Keep the sunflower visualization subtle (low opacity, positioned in corner/background)
2. Ensure text is large enough to be readable at small preview sizes
3. Leave generous margins (at least 60px on all sides)
4. The image should work well when cropped to square (for some platforms)

## Where It's Used
- Link previews on social media (Twitter, Facebook, LinkedIn)
- Messaging apps (iMessage, WhatsApp, Slack)
- Search results with rich snippets

## Quick Creation Options
1. **Figma/Canva:** Create using the brand colors above
